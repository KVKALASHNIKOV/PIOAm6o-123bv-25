# In-Memory Database: Библиотека

Прототип базы данных, работающей в оперативной памяти (in-memory), с консольным интерфейсом для управления коллекцией книг.

## Структура проекта

src/
└── db/
    ├── __init__.py
    ├── __main__.py
    ├── backend/
    │   └── memory.py
    └── tui.py

tests/
├── __init__.py
└── test_memory.py

## Реализованная функциональность

- Добавление записей
- Чтение всех записей
- Фильтрация по одному или нескольким полям
- Обновление записей
- Удаление записей
- Обработка ошибок (некорректный ввод, несуществующие записи)

## Установка и запуск

Требования:
- Python 3.10 или выше
- pytest

Запуск приложения:
python -m src.db

Запуск тестов:
pip install pytest
pytest tests/ -v
