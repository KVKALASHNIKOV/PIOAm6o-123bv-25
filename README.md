# Библиотека: In-Memory и File Database

Консольное приложение для управления коллекцией книг с поддержкой двух способов хранения данных:

* InMemoryDB — хранение данных в оперативной памяти;
* FileDB — хранение данных в JSON-файле с сохранением между запусками программы.

## Структура проекта

```text
src/
└── db/
    ├── __init__.py
    ├── __main__.py
    ├── tui.py
    └── backend/
        ├── __init__.py
        ├── memory.py
        └── file_db.py

tests/
├── __init__.py
├── test_memory.py
└── test_file_db.py
```

## Реализованная функциональность

* Добавление записей
* Просмотр всех записей
* Поиск по одному или нескольким полям
* Обновление записей
* Удаление записей
* Обработка ошибок пользовательского ввода
* Автоматическое сохранение данных в JSON-файл
* Загрузка данных из файла при запуске программы

## Реализации базы данных

### InMemoryDB

Хранит данные в оперативной памяти.

Особенности:

* высокая скорость работы;
* данные удаляются после завершения программы.

### FileDB

Хранит данные в JSON-файле.

Особенности:

* данные сохраняются между запусками программы;
* автоматическая загрузка данных при создании объекта базы данных;
* автоматическое сохранение после добавления, обновления и удаления записей.

## Формат хранения данных

Файловая база данных использует JSON-файл следующего вида:

```json
{
    "next_id": 2,
    "records": {
        "1": {
            "title": "1984",
            "author": "George Orwell",
            "year": 1949,
            "genre": "Dystopian"
        }
    }
}
```
