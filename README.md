# In-Memory Database: Библиотека

Прототип базы данных, работающей в оперативной памяти (in-memory), с консольным интерфейсом для управления коллекцией книг.

## Структура проекта
src/
└── db/
    ├── __init__.py
    ├── __main__.py
    ├── backend/
    │   └── memory.py          
    ├── tui.py                  
    └── models/
        └── book.py             

tests/
├── __init__.py
├── test_memory.py              
└── test_book.py                
## Реализованная функциональность

- Добавление записей
- Чтение всех записей
- Фильтрация по одному или нескольким полям
- Обновление записей
- Удаление записей
- Обработка ошибок (некорректный ввод, несуществующие записи)

## Инструкция по запуску

python -m src.db
